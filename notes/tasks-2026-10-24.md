# Ten Years: the work after the two reviews (24 October 2026)

Four packages, each owning its own files, so they can be done side by side. Contracts between them are listed at the end. A fifth pass (tests, README, commit) follows.

## Package 1: the body, the first fortnight, the account — owns `js/content/day.js`, `js/content/arrival.js`, `js/content/story.js`

1. **Spread the big costs so a man cannot die of one choice in his first week.**
   - The boots fight (arrival.js, choice `fight`): strength cost 16 → 10, and `S.until.ribs = S.day + 6`. While ribs: `drain()` adds 2, and "Work. Properly." costs 2 more (the ribs). The existing morning line about the ribs already covers the feel.
   - The cells (`cellsDay`): cost 22 → 14. The cells day no longer skips the night: after the cells screen go to `cellsNight()`, one paragraph (the cells at night: the cold through the planks, the bunk let down, the bread in the lining if it is still there), choices `sleep` (def) and, when `S.bread > 0`, `stash` ("Eat the N g you have kept.", `habit: false`, same effect as the night's stash), both to `endDay`. `routine: 'night'`.
   - Kuzma's half loaf, once, in the first fortnight: in `endDay`, before the verdict, if `S.day <= 14 && S.strength < 18 && S.kuzma.here && !S.flags.kuzmaHalf`: set the flag, `adj(+12)`, `mercy("Kuzma's half loaf, in the dark.")`, and `note(...)` a paragraph in Kuzma's voice (he breaks his bread without a word, "thin men are bad luck in a brigade", the story about the priest while you eat). It shows at the top of the account.

2. **Make decline legible in the account, in words.** Add `S.today.causes = {}` to `blankToday()` and a helper `cost(d, why)` in day.js that adds `d` to `S.today.causes[why]` and calls `adj(d)`. In `ledgerLines()`, right after the Body line, add one line built from the causes: the largest loss and the largest gain, e.g. `What took: the cold, then the work. What gave: the bowl.` (list up to two takers, one giver; omit a half when there is none). No numbers.

3. **Lev lives longer, and the office changes his mornings.** `levDaily`: −3/−5 per day → −2/−3 (−3 at ≤ −35). When `S.flags.levOffice` (set by package 2's `lev_repay`): no decline, +1 a day up to 60. Breakfast (`breakfast()`): when `levOffice && lev.alive`, the Lev line becomes "Lev eats at the office table now, with the trusties. He looks across once, and nods, and does not look again." and the "Break off a crust for Lev" choice is not offered.

4. **The eye predicts searches; small hoards survive more.** `searchChance(where)`: base count .12, gate .22; +.10 at eye ≥ 20, +.20 at ≥ 45, +.20 at ≥ 70, +.30 during `S.until.searches`; clamp .9. If `S.until.noSearch >= S.day` (package 2: Lev said Lubimov has the night off) return 0. In `search()`, the hoard is found with chance .35 when `S.bread >= 300`, .2 below.

5. **Day one must not repeat the arrival.** `FIRST_COUNT`: do not re-explain the fives and the double count (the railhead did); say it is the first count inside the wire, that it comes out wrong the first time "as Kuzma said it would". Day-one breakfast: do not repeat "hot water with a memory of cabbage" (the first supper said it); keep the bread sentence. Day-one reveille, second paragraph: the boots above your face belong to "the big man from the march" unless `S.flags.metSenka`, in which case "Senka's boots".

## Package 2: runs, events, the relationships — owns `js/engine.js`, `js/content/events.js`, `js/content/calendar.js`

## Package 4: the page — owns `js/ui.js`, `css/game.css`, `js/frames.js`, `js/assets.js`

1. **The clock takes the habit, not the first option.** In `present()`, the default index `d` is: on a screen whose `o.routine` is a habit key (a string), the index of the choice whose id is `S.habits[o.routine]`, when that exists; otherwise the `def` choice; otherwise 0. The timed pick calls `choose(ch, { timed: true })` (package 2 adds the argument) so a run-out clock never overwrites a habit; `pickChoice(k, timed)`.
2. **The clock scales with the screen.** `TIME` becomes per screen: `clamp(20000 + chars * 25, 30000, 60000)` where chars is the length of paragraphs plus choice labels and hints; `LATE` stays 6000. The bar and `clk.left` use the per-screen time.
3. **The run box for a run that did not get past its first day.** `runHtml` renders whenever `r` exists (package 2 guarantees a reason): with no days, just the reason line in the box.
4. **Phones:** under 520 px the id line and the tools stack (`#top .row` wraps; `.tools` on its own line, right-aligned) so the date is one line.
5. **Prints arrive before they are needed.** In frames.js add `warm(names)` that resolves each name through the stand-in chain to a file and creates an `Image` for it (cache only), and call it from `present()` in ui.js when `S.day` changes, with the day's likely prints: `'reveille'`, `'count_camp'`, `breakfastFrame(ration())`, `siteFrame(s)` for each of `SITES`, `'noon'`, `'gate'`, `'supper'`, `'supper_b'`, `'hut_night_pano'`, `'stove'`, `'wire'` (these helpers are globals from day.js). Use `requestIdleCallback` when present, else a short timeout.
6. **The wagon's stand-in:** in assets.js `arrival_wagon: 'cells'` (a plank box with a bench and a barred window reads as a wagon; the hut does not).

## Contracts between packages

- `S.today.site` ('power' | 'settlement' | 'timber' | null) and `todaySite()` — set in day.js (1), read by events.js (2) and lines.js (3).
- `S.flags.levOffice` — set by `lev_repay` (2), read by `levDaily`/`breakfast` (1) and lines (3).
- `S.flags.warnedDay`, `S.until.noSearch` — set by Lev's office events (2), read by `searchChance` (1).
- `S.flags.metSenka` — set by the arrival (exists), `senka_frost`, `others_escape` (2); read by day.js (1) and lines.js (3).
- `S.until.ribs` — set by the fight (1), read by `drain()` and work (1).
- `S.today.causes` and `cost()` — day.js only (1).
- `choose(ch, { timed })` — engine (2) provides, ui (4) calls.
- `S.habits['ev:' + id]` — engine/events (2) only.
- The run summary's reason — engine (2) sets, ui (4) renders.
