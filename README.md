# Ten Years

A text game about one day in a Soviet labour camp, 1951, repeated until the camp wins or you go through the wire.

## Play

Open `index.html` in a browser. Keys 1 to 4 or click. Headphones.

Sound works from a plain file. The strength-dependent muffling (a low-pass filter) only works when served over HTTP, because browsers refuse to route `file://` audio through Web Audio:

```bash
python3 -m http.server 8077
```

then open http://localhost:8077.

## Assets

Everything the game loads lives under `assets/` and is listed in `assets/manifest.json`. The game degrades silently when a file is missing, so you can play while assets trickle in.

- `assets/frames/<name>.png` — twelve selected linocut stills, one per scene (masters, ~3 MB each). The game loads the web copies in `assets/frames/web/<name>.jpg` first and falls back to the PNG; regenerate the copies after swapping a master with `sips -s format jpeg -s formatOptions 82 assets/frames/<name>.png --out assets/frames/web/<name>.jpg`. The page theme is cream paper and black ink to match the prints. Shot list and locked style prefix in `prompts/frames.md`; shared art direction in `prompts/frames-production.md`. Open `assets/frames/review.html` to review the set and all 36 variants. Exact generation prompts and source paths live in `assets/frames/production/`.
- `assets/sfx/<name>.mp3` — ambient loops and one-shots. Generated by `scripts/gen_sfx.py` from the manifest.
- `assets/voice/<line>.mp3` — character dialogue. Generated by `scripts/gen_voice.py` from the manifest. Voice ids live in `assets/voice/voices.json`, design previews in `assets/voice/previews/`.

## ElevenLabs scripts

Standard-library Python, no install. The key is read from `~/.config/elevenlabs/api-key.txt` or `ELEVENLABS_API_KEY` and never printed.

```bash
python3 scripts/gen_sfx.py                 # every missing sound
python3 scripts/gen_sfx.py --force rail    # regenerate one
python3 scripts/gen_voice.py design        # create voices that have no id yet
python3 scripts/gen_voice.py design --pick lev=2   # recreate Lev from preview 2
python3 scripts/gen_voice.py lines         # every missing line
python3 scripts/gen_voice.py lines --force kuzma_river
```

To change a voice: delete its entry in `voices.json` (or pick a different preview), then re-record its lines with `--force`.
To add a line: add it to `lines` in the manifest, reference it from `index.html` with `voice: 'line_id'`, run `lines`.

## Testing without playing

Open `index.html?dev` (or press the backtick key in the game) for the dev panel at the bottom of the page:

- **jump** to any scene or event with the state set in the fields (day, strength, bread, tobacco, brigade, eye, flags, Lev's tally). "read state" fills the fields from the current game.
- **walk all scenes** runs every scene and every choice on every screen headlessly and reports screens, choices and errors.
- **random ×200** / **careful ×50** play whole games with bots and report survival (median day, p90) and how each run ended. Random is a smoke test; careful is the balance check (a sensible player should last roughly 100 days).
- **dump script** downloads `script.txt`: every screen's text and choices, for reading the writing in one pass.

The same is available from the console: `DEV.walk()`, `DEV.sim('careful', 50)`, `DEV.dump()`, `DEV.jump('evKuzma')`, `DEV.scenes`.

## Structure of a day

Reveille, count and search, breakfast, the work site, one midday event, the gate search, dinner, night. Then a verdict on the day. Escape becomes an option at night once you hold any of: a blade, 600 g of bread, Senka, Kuzma's route.
